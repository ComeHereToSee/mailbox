# 网易 163 / 126 / yeah.net / 188 邮箱

网易邮箱需要开启 IMAP 服务，并使用**授权码**登录。Mailbox 会自动发送 IMAP `ID` 命令；不发送的话，网易服务器会报 `Unsafe Login`。

## 获取授权码

1. 打开网页版（如 <https://mail.163.com/>）并登录。
2. 进入 **设置 → POP3/SMTP/IMAP**。
3. 开启 **IMAP/SMTP 服务**，按提示用手机发送短信验证。
4. 复制页面上显示的**授权码**（只显示一次，记得保存）。
5. 回到 Mailbox，把授权码粘贴到“授权码”一栏，点 **测试并添加**。

如果需要 POP3，对应的服务器是 `pop.163.com:995` 等。网易企业邮（qiye.163.com）会在添加账户时根据 MX 记录自动识别。

## 常见问题

- **Unsafe Login**：确认 设置 → 账户 中“发送 IMAP ID”是打开的（默认打开）。
- **发信失败 550 / 554**：网易会拦截被判定为垃圾邮件的内容，也会限制发信频率。请稍后再试，或者调整正文内容。
