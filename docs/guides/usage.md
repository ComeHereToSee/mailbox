# 使用说明

## 界面

- **左栏**
  - 统一收件箱，以及每个账户的收件箱，未读数显示在右侧。
  - 智能邮箱：未读、星标、VIP、稍后提醒、置顶、有附件、草稿、已发送、归档、垃圾邮件、已删除。
  - 分类：主要、社交、推广、通知、论坛。
  - 你保存的智能文件夹。
  - 各账户的文件夹树：可以右键新建、重命名或删除；把邮件拖到文件夹上即可移动。
- **中栏**：邮件列表。默认按会话分组，可在“筛选”菜单里关闭。支持多选；在触控板上左右轻扫可以归档、删除、标记已读或加星标。
- **右栏**：会话阅读。可以展开和折叠每封邮件，下载或快速查看附件，回复会议邀请，退订，发送已读回执。
- **菜单栏图标**（Mailbox Helper）：显示未读数和最近的未读邮件，可以写新邮件、立即收信、暂停通知。关掉主窗口后也会继续收信。

## 键盘快捷键

单键快捷键（Gmail 风格）在邮件列表获得焦点时生效：

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `j` / `k` | 下一封 / 上一封 | `e` | 归档 |
| `#` / `⌫` | 删除 | `!` | 垃圾邮件 |
| `s` | 星标 | `u` | 标为未读 |
| `r` | 回复 | `a` | 全部回复 |
| `f` | 转发 | `c` | 写邮件 |
| `z` | 撤销上一步 | | |

菜单中的快捷键：

| 快捷键 | 作用 |
|---|---|
| `⌘N` | 写新邮件 |
| `⇧⌘N` | 检查新邮件 |
| `⌘R` / `⇧⌘R` / `⇧⌘F` | 回复 / 全部回复 / 转发 |
| `⌃⌘E` | 归档 |
| `⇧⌘U` / `⌥⌘U` | 标为已读 / 未读 |
| `⇧⌘L` | 星标 |
| `⇧⌘J` | 垃圾邮件 |
| `⇧⌘C` | 全部标为已读 |
| `⌘↩` | （写信窗口中）发送 |
| `⌘Z` | 撤销（提示条出现时） |

## 搜索语法

在搜索框里可以混合使用自由文本和下面这些条件。中文按双字切分，例如“报价”也能匹配到“报价单”。

| 写法 | 含义 |
|---|---|
| `合同 报价` | 同时包含这两个词 |
| `"季度 报告"` | 包含这个完整短语 |
| `-广告` | 不包含 |
| `from:张三` / `from:@qq.com` | 发件人 |
| `to:` / `cc:` | 收件人 / 抄送 |
| `subject:周报` | 主题 |
| `body:` / `filename:pdf` | 正文 / 附件名 |
| `has:attachment` | 有附件 |
| `is:unread` `is:starred` `is:pinned` `is:snoozed` `is:vip` | 状态 |
| `in:sent` `in:trash` `in:项目` | 文件夹 |
| `label:工作` `category:promotions` `account:QQ` | 标签 / 分类 / 账户 |
| `before:2026-01-31` `after:2026-01-01` | 日期范围 |
| `newer_than:7d` `older_than:1y` | 最近 7 天 / 一年以前 |
| `larger:5M` `smaller:100k` | 大小 |

- 搜索结果可以在“筛选”菜单里**保存为智能文件夹**。
- 本地只缓存最近一段时间的邮件（默认 90 天）。更早的邮件请在搜索结果底部点 **在服务器上搜索更多…**。

## 写信

- **格式**：工具栏提供字体、字号、粗体 / 斜体 / 下划线 / 删除线、颜色、列表、缩进、引用、对齐、链接、图片、表格、代码块、分隔线和清除格式。粘贴或拖入的图片会自动作为内嵌图片发送。
- **其他模式**：⋯ 菜单中可以切换 **Markdown 模式**、**纯文本**、**请求已读回执**、**标为重要**。
- **附件**：拖进写信窗口，或点“附件”按钮。
- **撤销发送**：发送后会在底部提示条显示“撤销”，时长可在 设置 → 写信 中调整。
- **定时发送**：点发送按钮右侧的箭头，选择“1 小时后”、“明天早上”或自定义时间。
- **模板**：在 设置 → 写信 中管理，写信时从“模板”菜单插入。
- **签名**：在 设置 → 账户 → 发件身份与签名 中设置。切换发件身份时会自动替换签名。
- **草稿**：每隔几秒自动保存。关闭写信窗口时会同步到服务器的草稿箱。
- **发送前检查**：没有主题或正文提到“附件”却没加附件时，会先提醒你。

## 规则

在 设置 → 规则 中创建，形式是“如果 … 那么 …”：

- **条件**：发件人、收件人、抄送、主题、正文、是否有附件、邮件列表、任意信头。
- **动作**：移动、归档、删除、标为已读、加星标、加标签、设为分类、转发、设为 VIP、不提醒、总是提醒、停止后续规则。
- **执行时机**：规则作用于新收到的邮件；也可以点“对收件箱执行”，处理已有的邮件。
- **服务器规则**：邮箱支持 ManageSieve 时，可以把规则上传到服务器，这样 Mac 关机时规则也会生效。

## 通知

- **格式**：通知标题形如 `[QQ·工作] 张三`，副标题是主题，正文是摘要。
- **直接操作**：可以在通知里快速回复、标为已读、归档或删除。
- **每个账户**（设置 → 通知）：可以单独开关，设置仅提醒 VIP、提醒哪些分类、是否有声音。
- **免打扰**：可设置免打扰时段（VIP 来信仍会提醒），菜单栏里也可以暂停通知。
- **推送到手机或聊天工具**：见 [push.md](push.md)。

## 隐私

- **远程内容**：默认不加载远程图片，并拦截邮件跟踪像素。可以单封显示，也可以“始终显示此发件人的图片”。
- **钓鱼提示**：链接显示的地址和实际地址不一致、发件人名称伪装成另一个邮箱时，会显示红色警告。
- **本地数据**：邮件正文加密保存在本机，密钥放在钥匙串里；账户密码和令牌也加密保存。
- **应用锁**：可以开启 Touch ID 应用锁（设置 → 隐私）。

## 加密邮件（PGP / S/MIME）

- **密钥**：在 设置 → 加密 中管理。
  - 生成一把新的 PGP 密钥，或导入已有的（GnuPG 导出的 `.asc`）。
  - S/MIME 证书请导入 `.p12` / `.pfx` 文件，从钥匙串或 Windows 导出的都可以。
  - 联系人的公钥可以粘贴、导入文件，或从对方发来的 S/MIME 签名邮件中自动保存。
- **收信**：加密邮件会自动解密，签名会自动验证。阅读区顶部显示“已解密”“签名有效”或“签名无效”。
  - 加密邮件的正文不会写入搜索索引。
- **发信**：写信窗口底部有 ✍︎（签名）和 🔒（加密）两个开关。
  - 所有收件人都有公钥时，会自动打开加密。
  - 有人缺公钥时，锁会变红，并列出缺公钥的地址。
  - 加密邮件也会用你自己的公钥加密一份，所以“已发送”里的副本你仍然能看。
- **分享公钥**：在密钥右侧的 ⋯ 菜单里复制或导出公钥，然后发给联系人。
- **私钥口令**：带口令的 PGP 私钥可以在 ⋯ 菜单中“设置私钥口令”，保存后签名和解密时不再询问。

## 其他集成

- **默认邮件应用**：可在 设置 → 通用 中设为默认，网页上的 `mailto:` 链接会用 Mailbox 打开。
- **分享**：在任意应用的“分享”菜单里选 Mailbox，可以把文件、链接或文字发成新邮件；也可以选中文字后用右键 → 服务 → “用 Mailbox 发送”。
- **日历与提醒事项**：邮件的“更多”菜单可以加入日历、创建提醒事项、打印、导出 PDF、存为 .eml、查看原始邮件，或分享到微信 / QQ / AirDrop。
- **Spotlight**：可以在 Spotlight 里搜索最近的邮件。
- **快捷指令**：提供“写邮件”、“发送邮件”和“未读邮件数”三个动作。
