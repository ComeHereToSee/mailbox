# Gmail

Gmail 有两种接入方式，任选其一：

- **A. 应用专用密码**：最简单，需要先开启两步验证。
- **B. 浏览器登录（OAuth）**：像在 Chrome 里登录一样，但需要你自己在 Google Cloud 注册一个客户端（一次性操作）。

## A. 应用专用密码

1. 打开 <https://myaccount.google.com/security>，确认已开启**两步验证**。
2. 打开 <https://myaccount.google.com/apppasswords>，新建一个名为 “Mailbox” 的应用专用密码，复制那 16 位密码。
3. 在 Mailbox 中选择 Gmail → **改用应用专用密码**，填写邮箱地址和这个密码，点 **测试并添加**。

## B. 浏览器登录（OAuth）

Google 要求每个第三方应用使用自己注册的客户端。自用的话，在“测试 / 未验证”状态下即可使用。

1. 打开 <https://console.cloud.google.com/>，新建一个项目（例如 “Mailbox”）。
2. **API 和服务 → 启用 API 和服务**：搜索并启用 **Gmail API**。这一步不是必须的，但能避免一些控制台提示。
3. **OAuth 同意屏幕**：
   - 用户类型选“外部”，填写应用名称和你的邮箱。
   - 添加范围 `https://mail.google.com/`。
   - 在“测试用户”中添加你自己的 Gmail 地址。
4. **凭据 → 创建凭据 → OAuth 客户端 ID**：应用类型选 **桌面应用**，创建后会得到**客户端 ID** 和**客户端密钥**。
5. 在 Mailbox 的 设置 → 高级 → OAuth 中，填写 Google 客户端 ID 和密钥。
6. 添加账户时选择 Gmail → **在浏览器中登录**，在浏览器里完成授权即可。

> 注意：处于“测试”状态的 Google 应用，刷新令牌 7 天就会过期，之后需要在 设置 → 账户 中点“重新登录”。
> 把应用“发布”为生产状态（不需要提交验证）可以避免这一点；登录时会显示“Google 尚未验证此应用”，点 **高级 → 继续** 即可。自用、或 100 个用户以内都可以这样用。

## 服务器

imap.gmail.com:993（SSL/TLS），smtp.gmail.com:465（SSL/TLS）。Gmail 会自动把发出的邮件存进“已发送”，所以 Mailbox 默认不会再追加一份副本。

## 说明

- Gmail 的标签在 IMAP 里表现为文件夹。“所有邮件 / 重要 / 已加星标”这些虚拟文件夹默认不同步，避免邮件重复；需要时可以在文件夹右键菜单中手动同步。
- 归档：在 Gmail 里会把邮件移到“所有邮件”，和网页版的“归档”效果一致。
